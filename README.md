# Laser Defender
A fast-paced 2D space shooter built with Unity and C#. Take control of your spacecraft and face relentless waves of enemy ships — destroy as many as you can before they destroy you.
Gameplay
The player controls a spacecraft that moves freely across the screen, firing lasers at incoming enemy formations. Enemies follow predefined paths and shoot back. The game ends when the player's health is depleted.
Core mechanics:

Player movement — smooth, responsive controls across the play area
Laser firing — continuous rapid-fire shooting
Enemy waves — scripted formations that patrol and attack
Health system — both player and enemies have hit points
Score tracking — points awarded for each enemy destroyed

## Features

Scrolling space background for an immersive feel
Multiple enemy types with unique movement paths
Collision detection and explosion effects
Music and sound effects
High score display

## Tech Stack

Engine: Unity (2D)
Language: C#
Physics: Unity 2D Collider system
Audio: Unity Audio Source components

## How to Run

Clone the repository
Open the project folder in Unity Hub
Load the main scene from the Scenes folder
Press Play in the Unity Editor
